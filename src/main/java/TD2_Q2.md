## Question 2
- **JUnit** : framework utilisé pour écrire et exécuter les tests unitaires.

- **Hamcrest** : bibliothèque qui permet d’écrire des assertions plus lisibles grâce aux matchers.

- **Mockito** : outil permettant de créer facilement des objets simulés (mocks, stubs, spies) pour isoler le code testé.

- **JaCoCo** : outil de mesure de la couverture de code, qui indique quelles parties du programme sont exécutées par les tests.s** une bibliothèque de test — c'est un outil de mesure de couverture de code (indique quelles lignes/branches ont été exécutées par les tests).
